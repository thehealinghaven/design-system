# Slide masters — 16:9, 1920 × 1080

Five slide types, recreated from the deck master in `thehealinghaven/brand-kit` (§F · Slide-deck master) at their real pixel sizes, then scaled to 1280×720 for the card preview.

| File | Type | Ground |
|---|---|---|
| `title.html` | Title, split with a warm photo | Charcoal + photo panel |
| `section.html` | Section header | Wood-deep |
| `body.html` | Body with gold arrow bullets | Cream |
| `quote.html` | Pull-quote, fire accent | Charcoal |
| `closing.html` | Closing / CTA | Signature gradient |

Type sizes are the master's: 116px title, 96px section + quote, 82px body title, 40px body copy, 26–30px tracked kickers. Never go below 24px on a 1920px slide.
