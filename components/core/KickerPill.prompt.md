The filled kicker label that opens a social card or flyer.

```jsx
<KickerPill size="lg" background="var(--pillar-community)">Community</KickerPill>
```

Use the pillar accent token for the day's pillar (Mon teal, Tue fire, Wed terracotta, Thu gold-mid, Fri deep green, Sat gold-mid, Sun fire). On web, prefer `Eyebrow` instead — the pill is a social/print device.
