Primary actions and links. Label copy is short, tracked, ALL CAPS, and usually ends in a → for forward motion.

```jsx
<Button variant="primary">Begin a Consult →</Button>
<Button variant="dark">Member Login</Button>
<Button variant="underline">Learn how I work</Button>
```

One `primary` per view. `dark` is the portal/login pair. `underline` and `ghost` carry everything else. Copy pattern: "Begin a Consult →", "Book the Free 15-Min Consult", "Learn how I work →".
