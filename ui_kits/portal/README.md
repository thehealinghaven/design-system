# UI kit — member portal

Two screens, click-through: **Login** (split charcoal/cream, breathing ring, magic-link alternative) → **Dashboard** (charcoal rail, sessions list, documents list, the signature-gradient membership card, a between-sessions practice and a note from Helen).

Grounded in the sources: the `Member Login` button variant, the "portal membership card" called out as the home of the charcoal→gold signature gradient, documents, and between-session messaging. Fees and rates are deliberately not shown. `--surface-functional` (pure white) is used for the in-product lists and forms, exactly as the color rules require.

**Inference note:** no portal source code exists in the two repos, so screen inventory and information architecture are inferred from those references. Treat this as a visual proposal in the correct brand language rather than a recreation.
